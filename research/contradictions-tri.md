# Tri des candidats de contradictions

Contrôle au 10 octobre 2026. Critère : deux engagements impossibles à tenir ensemble ou deux chiffrages opposés de la même mesure. Les identifiants ont été recherchés dans les YAML des programmes ; pour chaque identifiant valide, la page annoncée a été ouverte dans `data/corpus/*.json`. Les JSON candidats ne sont pas des sources. Les sources en ligne des documents sont recensées dans [le manifeste](../sources/manifest.json) ; les pièces officielles et les limites de leur collecte sont décrites dans [la méthode](../content/pages/methode.md).

Aucun nouveau candidat n'atteint le critère. Les trois fichiers `lfi-europe-international.json`, `rn-immigration.json` et `rn-services-publics.json` sont tronqués : leurs paires lisibles ont été examinées ; un éventuel fragment coupé ne peut pas être évalué.
